# 修改记录（Changelog）

本文件记录即刻设计（InstantDesign）的重要变更，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased] - 2026-09-27

### 破坏性变更（Breaking Changes）

- 方法重命名：`editor.reLoadFromJSON()` → `editor.reloadFromJSON()`
- 方法重命名：`editor.reLoad()` → `editor.reload()`
- 事件重命名：`loadJSONBefore` / `loadJSONAfter` → `loadBefore` / `loadAfter`

### 行为变更

- `editor.reload(frame)` 现在也会触发 `loadBefore` / `loadAfter` 事件

### 迁移指南

- 将 `editor.reLoadFromJSON(json)` 替换为 `editor.reloadFromJSON(json)`
- 将 `editor.reLoad(frame)` 替换为 `editor.reload(frame)`
- 将事件监听 `editor.eventBus.on(editor.Events.loadJSONAfter, fn)` 替换为 `editor.eventBus.on(editor.Events.loadAfter, fn)`
- 旧名称不再保留兼容别名
