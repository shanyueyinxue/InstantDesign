## 1. 总览

项目采用**双层国际化**设计：

| 层 | 引擎 | 作用范围 | 文案根命名空间 |
| --- | --- | --- | --- |
| UI 层 | `vue-i18n` | Vue 组件模板 / 组合式 API（header、panel、footer 等布局 UI） | `leaferEditorLayouts` |
| 内核层 | `i18next` | 与 Vue 解耦的内核逻辑（右键菜单、浮动工具条等插件） | `leaferEditorPlugins` |

这样划分的原因：内核 `LeaferEditor` 是一个**可独立复用的库**，不应强依赖 Vue 及其 i18n 方案，因此内核单独使用框架无关的 `i18next`；而布局 UI 全部由 Vue 组件构成，直接使用生态更成熟的 `vue-i18n`。两层通过当前语言变量 `localeType` 在运行时保持同步。

同时，UI 组件库 **Arco Design Vue** 拥有自己的语言包，通过 `a-config-provider` 单独同步。

## 2. 双层 i18n 架构

```
                        ┌─────────────────────────────┐
                        │  src/i18n/consts.ts          │
                        │  localeType (ref, 单一真源)  │
                        └──────────────┬──────────────┘
                                       │ watch
                        ┌──────────────▼──────────────┐
                        │  src/App.vue                 │
                        │  watch(localeType) 同步三方   │
                        └───┬───────────┬───────────┬─┘
                            │           │           │
             i18n.locale ───┘           │           └─── setLocale()
             (vue-i18n)                  │                (i18next)
                                         │
                              arcolocale (computed)
                              a-config-provider
                              (Arco Design 语言包)
```

- `localeType` 是唯一的状态源（`src/i18n/consts.ts` 中的 `ref`）。
- 任意位置修改 `localeType.value` 即可触发 `App.vue` 的 `watch`，从而同步 vue-i18n、i18next 与 Arco 三方语言。
- Arco 的语言通过 `computed`（`arcolocale`）自动跟随，无需手动调用。

## 4. UI 层：vue-i18n

### 4.1 语言常量与当前语言

`src/i18n/consts.ts` 定义了所有受支持语言的代码常量、显示名，以及全局当前语言 `localeType`：

```ts
import { ref } from "vue";

export const zh_CN = "zh-CN";
export const en_US = "en-US";
export const ja_JP = "ja-JP";
// ... 其余语言代码常量

const languageLabels: Record<string, string> = {
    [zh_CN]: "中文",
    [en_US]: "English",
    [ja_JP]: "日本語",
    // ...
};
export const getLanguageLabel = (language: string) => languageLabels[language] || language;

export const localeType = ref(zh_CN);   // 单一真源：当前语言
```

> 注意：`consts.ts` 中列出了 13 种语言代码，但**实际注册文案的只有部分语言**（见下文）。其余常量是为将来扩展预留的占位。

### 4.2 vue-i18n 实例

`src/i18n/i18n.ts` 创建 `vue-i18n` 实例（Composition API 模式），并注册应用级语言包：

```ts
import { createI18n } from "vue-i18n";
import { computed } from "vue";
import { arcolocaleOptions } from "./arcoI18n";
import { zh_CN, en_US } from "./consts";
import zh from "../locales/zh-CN.json";
import en from "../locales/en-US.json";

const messages = {
    [en_US]: en,
    [zh_CN]: zh,
};

// langOptions：应用语言包与 Arco 语言包的交集
export const langOptions = computed(() => {
    const msgKeys = Object.keys(messages);
    return arcolocaleOptions.value.filter(item => msgKeys.includes(item));
});

const i18n = createI18n({
    legacy: false,            // 使用 Composition API 模式
    locale: zh_CN,            // 默认语言
    fallbackLocale: zh_CN,    // 回退语言
    globalInjection: true,    // 全局注入 $t
    messages,
});

export default i18n;
```

关键点：

- `legacy: false`：使用组合式 API，组件中通过 `useI18n()` 获取 `t`。
- `globalInjection: true`：模板中可直接使用 `$t('...')`。
- 默认语言与回退语言均为 `zh-CN`。
- `langOptions` 用于筛选出「既有应用文案、又有 Arco 语言包」的语言，可作为语言选择器数据源。

### 4.3 Arco Design 组件库语言

`src/i18n/arcoI18n.ts` 把项目语言代码映射到 Arco Design 的语言包对象：

```ts
import { computed } from "vue";
import zhCN from "@arco-design/web-vue/es/locale/lang/zh-cn";
import enUS from "@arco-design/web-vue/es/locale/lang/en-us";
import { zh_CN, en_US, localeType } from "./consts";

const locales: Record<string, any> = {};
locales[zh_CN] = zhCN;
locales[en_US] = enUS;

export const arcolocale = computed(() => locales[localeType.value] || zhCN);
export const arcolocaleOptions = computed(() => Object.keys(locales));
```

`App.vue` 中通过 `a-config-provider` 应用：

```vue
<a-config-provider :locale="arcolocale">
    <RouterView />
</a-config-provider>
```

这样 Arco 组件的内置文案（如分页、日期选择器）会随 `localeType` 自动切换。

### 4.4 布局文案合并

布局 UI 的大体量文案存放在 `src/LeaferEditor/layouts/locales/`，根键为 `leaferEditorLayouts`，在 `layout.vue` 挂载时合并进 vue-i18n：

```ts
// src/LeaferEditor/layouts/layout.vue
import { useI18n } from "vue-i18n";
import { locales } from "./locales";

const i18n = useI18n();
for (const key in locales) {
    i18n.mergeLocaleMessage(key, locales[key]);
}
```

`locales/index.ts` 目前注册了 `zh-CN` 与 `en-US`：

```ts
import zh from "./zh-CN.json";
import en from "./en-US.json";

export const locales: Record<string, typeof zh> = {
    "zh-CN": zh,
    "en-US": en,
};
```

组件中按命名空间引用，例如：

```vue
<span>{{ $t('leaferEditorLayouts.footer.copyright') }}</span>
```

```ts
import { useI18n } from "vue-i18n";
const { t } = useI18n();
const label = t('leaferEditorLayouts.panelRight.attribute.arrow.title');
```

## 5. 内核层：i18next

内核使用与框架无关的 `i18next`，入口为 `src/LeaferEditor/i18n/index.ts`：

```ts
import i18next from 'i18next'
import zh from './locales/zh-CN.json'
import en from './locales/en-US.json'

const instance = i18next.createInstance()

instance.init({
    lng: 'zh-CN',
    fallbackLng: 'zh-CN',
    resources: {
        'zh-CN': { translation: zh },
        'en-US': { translation: en },
    },
})

export const t = (key: string, options?: Record<string, any>): string =>
    instance.t(key, options)

export const setLocale = (locale: string) => instance.changeLanguage(locale)
export const getLocale = (): string => instance.language
export const addResources = (locale: string, resources: LocaleJSON) =>
    instance.addResourceBundle(locale, 'translation', resources, true, true)
```

这些 API 从内核入口统一导出（`src/LeaferEditor/index.ts`）：

```ts
export { setLocale, getLocale, addResources, t } from './i18n';
```

内核插件在需要文案时直接调用 `t`，例如右键菜单与浮动工具条：

```ts
// src/LeaferEditor/plugins/contextMenu.ts
import { t } from "../i18n"
// ...
{ title: t("leaferEditorPlugins.add.rect.title"), ... }

// src/LeaferEditor/plugins/toolBar.ts
import { t } from "../i18n"
{ id: "copy", help: () => t("leaferEditorPlugins.copy"), ... }
```

内核文案根键为 `leaferEditorPlugins`，目前包含 `copy / cut / paste / zoom / grid / zIndex / add / operate` 等分组。

> 与 UI 层不同，内核 `t` 返回的是**普通字符串而非响应式值**。右键菜单、工具条在创建时即读取文案，运行时切换语言后，已构建的菜单需要重建才能反映新语言（重新创建DOM）。

## 6. 运行时语言切换机制

`App.vue` 是三方语言的同步中枢：

```ts
import { useI18n } from 'vue-i18n';
import { watch } from 'vue';
import { arcolocale, localeType } from './i18n';
import { setLocale, addResources } from './LeaferEditor';

const i18n = useI18n();

// 动态注册日语文案（应用层 + 内核层）
i18n.mergeLocaleMessage(ja_JP, ja)
addResources("ja-JP", { leaferEditorPlugins: { /* ... */ } })

watch(localeType, (newVal) => {
    i18n.locale.value = newVal;   // 1. vue-i18n
    setLocale(newVal);            // 2. i18next
});
```

配合模板中的 `<a-config-provider :locale="arcolocale">`，完整切换链路为：

1. 修改 `localeType.value`；
2. `watch` 触发 → `i18n.locale.value = newVal`（Vue 组件文案更新）；
3. `watch` 触发 → `setLocale(newVal)`（内核插件文案更新）；
4. `arcolocale` 计算属性变化 → `a-config-provider` 更新（Arco 组件文案更新）。

一个最简单的切换示例见 `src/views/actions/githubBtn.vue`：

```ts
import { localeType } from '../../i18n';
import { zh_CN, en_US, ja_JP } from '../../i18n/consts';

const locales = [zh_CN, en_US, ja_JP];
const onClick = () => {
    n = (n + 1) % locales.length;
    localeType.value = locales[n] || zh_CN;
};
```

> 项目当前**不包含**语言持久化（localStorage）与浏览器语言自动检测，默认始终为 `zh-CN`。如需持久化，可在 `consts.ts` 初始化时读取 `localStorage`，并在 `watch` 中写回。

## 8. 新增一门语言

以新增 `fr-FR` 为例，完整步骤如下。

### 步骤 1：添加语言代码与显示名

`src/i18n/consts.ts`（语言代码常量 `fr_FR` 已存在，若无则新增，并补充 `languageLabels` 中的显示名）。

### 步骤 2：注册 Arco 语言包

`src/i18n/arcoI18n.ts`：

```ts
import frFR from "@arco-design/web-vue/es/locale/lang/fr-fr";
import { fr_FR } from "./consts";

locales[fr_FR] = frFR;
```

> 若 Arco 没有对应语言包，`arcolocale` 会自动回退到 `zh-CN`，不影响运行。

### 步骤 3：添加应用级文案并注册

1. 新建 `src/locales/fr-FR.json`；
2. 在 `src/i18n/i18n.ts` 的 `messages` 中注册：

```ts
import fr from "../locales/fr-FR.json";
const messages = {
    [en_US]: en,
    [zh_CN]: zh,
    [fr_FR]: fr,
};
```

### 步骤 4：添加布局 UI 文案并注册

1. 新建 `src/LeaferEditor/layouts/locales/fr-FR.json`（复制 `zh-CN.json` 并翻译，保留 `leaferEditorLayouts` 根键与全部键路径）；
2. 在 `src/LeaferEditor/layouts/locales/index.ts` 注册：

```ts
import fr from "./fr-FR.json";
export const locales: Record<string, typeof zh> = {
    "zh-CN": zh,
    "en-US": en,
    "fr-FR": fr,
};
```

### 步骤 5：添加内核文案并注册

1. 新建 `src/LeaferEditor/i18n/locales/fr-FR.json`（保留 `leaferEditorPlugins` 根键）；
2. 在 `src/LeaferEditor/i18n/index.ts` 的 `resources` 中注册：

```ts
import fr from './locales/fr-FR.json'
resources: {
    'zh-CN': { translation: zh },
    'en-US': { translation: en },
    'fr-FR': { translation: fr },
},
```

### 步骤 6：接入语言选择器

将 `fr_FR` 加入语言选择器列表即可（参考 `githubBtn.vue`）。切换时 `App.vue` 的 `watch` 会自动同步三方。

> 也可像 `App.vue` 对日语的处理那样，采用**运行时动态注册**的方式（`i18n.mergeLocaleMessage` + `addResources`），从而避免修改 `messages` / `resources` 的静态注册。两种方式可任选其一。

## 9. 运行时扩展文案

对于由第三方或业务动态提供的文案，可在运行时向两层分别注入。

**UI 层（vue-i18n）**：

```ts
import { useI18n } from "vue-i18n";
const i18n = useI18n();
i18n.mergeLocaleMessage("fr-FR", {
    myModule: { hello: "Bonjour" },
});
```

**内核层（i18next）**：

```ts
import { addResources } from "./LeaferEditor";

addResources("fr-FR", {
    leaferEditorPlugins: {
        copy: "Copier",
        // ... 其余键
    },
});
```

> `addResources` 的 `resources` 类型为内核 `zh-CN.json` 的结构（`LocaleJSON`），第四个参数 `deep=true, overwrite=true` 表示深合并并覆盖同名键。

## 10. 注意事项与最佳实践

1. **保持两层文案同步**：新增语言时务必同时处理 UI 层（`layouts/locales` + `locales`）和内核层（`LeaferEditor/i18n/locales`），否则会出现「面板已翻译、右键菜单仍是中文」的混搭现象。
2. **命名空间不要改**：UI 层统一 `leaferEditorLayouts`，内核层统一 `leaferEditorPlugins`，便于区分与合并。
3. **键路径必须完整**：翻译 JSON 应保持与源语言完全一致的键结构，缺失键会回退到 `fallbackLocale`（`zh-CN`）。
4. **内核文案非响应式**：内核 `t` 只在调用时求值；运行时切换语言后，需要重建才能刷新右键菜单 / 工具条文案。
5. **Arco 回退**：未在 `arcoI18n.ts` 注册的语言，Arco 组件将回退为中文，但应用自定义文案不受影响。
6. **默认与回退语言**：均为 `zh-CN`；新增语言后建议明确设置 `fallbackLocale` 策略。
7. **持久化 / 自动检测（可选）**：当前未实现，如需可在 `consts.ts` 中初始化 `localeType`，并在 `App.vue` 的 `watch` 中写回存储。
8. **`langOptions`**：它是「应用文案语言」与「Arco 语言」的交集，适合作为语言选择器的数据源，避免出现只有 Arco 没有文案（或反之）的选项。
