## 1. 快速开始

完整接入示例（摘自 `src/views/HomeView.vue`）：

```vue
<template>
    <LeaferEditorLayout
        ref="layoutRef"
        :editorOptions="editorOptions"
        :options="options"
        :apis="apis"
        :sloganName="sloganName"
        logoUrl="/logo.png"
    />
</template>

<script setup lang="ts">
import LeaferEditorLayout from "../LeaferEditor/layouts/layout.vue";
import { DEFAULT_API } from "../mock";
import type { LayoutOptions, LayoutApiOptions } from "../LeaferEditor/layouts/layoutOptions";
import type { EditorLayoutOptions } from "../LeaferEditor/layouts/layout.vue";

const layoutRef = ref<InstanceType<typeof LeaferEditorLayout>>();
const apis: LayoutApiOptions = DEFAULT_API;

const editorOptions: EditorLayoutOptions = {
    canvas: { width: 1000, height: 1000, fill: "#f5f7fd", zoomMode: "mouse", lockRatio: "corner" },
    history: { maxSize: 64 },
    ruler: { dpi: 96, gridLine: { strokeDragColor: "#ff0800ff" } },
    shortcut: { global: true },
    image: { fileTypes: ["image/jpeg", "image/png", "image/webp"], maxSize: 10 * 1024 * 1024 },
};

const options: LayoutOptions = {
    export: { showCurrentPageJSON: false, preview: { format: "jpg" } },
    isShowFooterBar: false,
    isShowPageText: true,
};

// 通过 ref 拿到编辑器实例
// layoutRef.value?.editor
</script>
```

- `LeaferEditorLayout` 内部会自动 `createLeaferEditor(editorOptions)` 并安装内置插件（Ruler / Shortcut / ContextMenu / ToolBar / Snap）。
- 若只想使用纯内核（不要 UI 布局），直接调用 `createLeaferEditor()` 并自行挂载 `editor.view`。

## 2. createLeaferEditor 选项

```ts
import { createLeaferEditor } from "../LeaferEditor";

const editor = createLeaferEditor(options?: LeaferEditorOptions);
```

`LeaferEditorOptions` 定义于 `src/LeaferEditor/core/interfaces/editor.ts`：

```ts
interface LeaferEditorOptions {
    canvas?: EditorCanvasOptions;
    page?: EditorPageOptions;
    history?: EditorHistoryOptions;
    image?: EditorImageOptions;
    font?: EditorFontOptions;
}
```

### canvas —— `EditorCanvasOptions`

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `width` | `number` | `600` | 初始画布宽（也作为新建页面的宽） |
| `height` | `number` | `600` | 初始画布高 |
| `fill` | `string` | `"#FFF"` | 视口背景色（App 的 `fill`） |
| `contentFill` | `string` | `"transparent"` | **内容层 Frame** 的背景色 |
| `lockRatio` | `boolean \| "corner"` | `false` | 编辑框是否锁定宽高比，`"corner"` 仅角点等比 |
| `disabledMove` | `boolean` | `false` | 是否禁用视图平移（拖拽画布） |
| `disabledWheel` | `boolean` | `false` | 是否禁用滚轮事件 |
| `zoomMode` | `boolean \| "mouse"` | `false` | 滚轮是否直接缩放（`"mouse"` 以鼠标为中心） |
| `hideOnMove` | `boolean` | `false` | 拖动元素时是否隐藏编辑框 |

### page —— `EditorPageOptions`

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `changePageZoomFit` | `boolean` | `true` | 切换页面后是否自动 `zoom('fit')` |

### history —— `EditorHistoryOptions`

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | 是否启用撤销 / 重做 |
| `maxSize` | `number` | `20` | 每个页面的历史最大步数 |

> 历史记录是**按页面独立**的（`HistoryManager` 内部 `Map<pageId, History>`）。

### image —— `EditorImageOptions`

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `fileTypes` | `string[]` | `[]`（即 `image/*`） | 允许的 MIME 类型，用于文件选择与校验 |
| `maxSize` | `number` | `10MB` | 单文件大小上限（字节） |
| `uploadCallback` | `(file, sourceTag, image?) => Promise<{ url, width?, height?, name? }>` | 读取为 base64 | 图片上传回调。默认 `readFileAsDataURL`；接真实后端时替换为上传接口 |

`uploadCallback` 的 `sourceTag` 为 `ImageSourceTag`（`OpenImage` / `Base64` / `Blob` 等），便于区分图片来源。

### font —— `EditorFontOptions`

| 选项 | 类型 | 说明 |
| --- | --- | --- |
| `onFontsNotFound` | `(missingFontNames: string[]) => Promise<FontInfo[]> \| FontInfo[]` | 加载 JSON 时若发现本地未注册字体，回调返回 `FontInfo[]` 以自动注册（有 10s 超时保护） |

`FontInfo` 结构：`{ code, name, preview?, variants: { url, format, weight?, style? }[] }`。

## 3. 编辑器实例 API 与创建功能

`LeaferEditor` 继承自 `PluginHost`，既是编辑器也是插件宿主。

### 3.1 实例属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `options` | `LeaferEditorOptions` | 合并默认值后的配置 |
| `app` | `App` | 底层 Leafer App 实例（`editor.app.editor` 为 leafer 编辑器） |
| `view` | `HTMLElement` | 画布 DOM，需自行挂载 |
| `eventBus` | `MittBus` | 类型安全事件总线 |
| `Events` | `typeof EventTypes` | 事件枚举 |
| `selected` | `IUI[]` | 当前选中元素 |
| `currentScale` | `number` | 当前缩放比例（可读写） |
| `canvasWidth` / `canvasHeight` | `number` | 画布宽 / 高 |
| `page` / `history` / `layer` / `mode` / `image` / `clipboard` / `font` | Manager | 七大管理器 |

### 3.2 画布与页面

```ts
editor.page.add()                    // 新增页面并切换（返回 id）
editor.page.add(id?, setCurrent?, metaData?)
editor.page.setCurrent(id)           // 切换页面
editor.page.remove(id)               // 删除页面（最后一个不可删）
editor.page.next() / editor.page.prev()
editor.page.list()                   // Canvas[]
editor.page.current                  // 当前 Canvas
editor.page.currentID                // 当前页面 id

editor.resize(w, h, syncCanvasSize?) // 视口尺寸变化
editor.canvasResize(w, h)            // 修改画布尺寸并触发 canvasResize 事件
editor.clear()                       // 清空当前页 ground/content/sky
editor.clearContent() / clearGround() / clearSky()
```

页面由 `Canvas` 表示，包含三个 Frame：

- `groundFrame`：背景棋盘格（透明底）
- `contentFrame`：**内容层**，所有设计元素默认加在此
- `skyFrame`：顶层（不可交互，常用于水印/蒙层）

```ts
const page = editor.page.current;
page.width / page.height;            // 可读写（写会 resize）
page.metaData;                       // { cover?, title?, author?, description?, ... }
page.contentLayers;                  // 内容层元素（过滤 NoLayer）
page.add(ui, index?, parent?);
page.replaceContent(children);
page.toJSON() / page.exportContentJSON();
```

### 3.3 元素创建（predefine / 扩展图形）

内核提供 `predefine` 工厂函数（`src/LeaferEditor/core/utils/predefine.ts`），所有函数接收 `Partial<IUIInputData>` 覆盖默认值：

| 函数 | 生成元素 | 默认尺寸 / 关键参数 |
| --- | --- | --- |
| `rect(options?)` | 矩形 `Rect` | 100×100，`fill: "red"` |
| `roundedRect(options?)` | 圆角矩形 | 100×100，`cornerRadius: 20` |
| `triangle` / `pentagon` / `polygon` | 多边形 `Polygon` | 100×100，`sides: 3 / 5 / 5` |
| `roundedPentagon` | 圆角六边形 | 100×100，`sides: 6, cornerRadius: 20` |
| `threeStar` / `pentagram` / `star` | 星形 `Star` | 100×100，`corners: 3 / 5`，`innerRadius: 0.15` |
| `roundedStar` | 圆角星形 | 100×100，`corners: 8, innerRadius: 0.5, cornerRadius: 5` |
| `ellipse` | 圆形 `Ellipse` | 100×100 |
| `ring` | 圆环 | 100×100，`innerRadius: 0.5` |
| `sector` | 扇形 | 100×100，`startAngle: -60, endAngle: 180` |
| `ellipse2` | 椭圆 | 50×100 |
| `text(options?)` | 文本 `Text` | 文本 `"即刻设计-双击编辑"`，`fontSize: 24`，`fontFamily: "阿里巴巴普惠体"` |
| `line(options?)` | 线段 `Line` | 100，`strokeWidth: 5`，`rotation: 45` |
| `arrow(options?)` | 箭头 `Arrow` | 100，`strokeWidth: 5`，`rotation: 45` |

```ts
import { utils } from "../LeaferEditor";
const { predefine } = utils;

editor.add(predefine.text({ text: "标题", fontSize: 36, fill: "#333" }));
```

**扩展图形（自定义注册的 UI）**：`src/LeaferEditor/core/shapes`

- `QrCode`（二维码）：`{ text, size, options?, logo?, logoSize?, logoPadding? }`，`lockRatio: true`
- `BarCode`（一维码）：`{ text, codeHeight, codeUnitWidth?, format?='CODE128', font?, textPosition?, fontSize?, lineColor?, background?, margin? }`，`lockRatio: true`
- `HTMLTable`：表格

```ts
import BarCode from "../LeaferEditor/core/shapes/BarCode";
import QrCode from "../LeaferEditor/core/shapes/QrCode";

editor.add(new QrCode({ text: "https://example.com", size: 120 }));
editor.add(new BarCode({ text: "123456789", codeHeight: 100 }));
```

> 创建后建议调用 `editor.setNormalizeAttr(ui)` 补全 `id/name/zIndex/editable`，再 `editor.add(ui)`。左侧「添加」面板的创建按钮正是这样做的。

### 3.4 元素增删与编组

```ts
editor.add(child, index?)            // 添加并自动选中、保存历史
editor.addMany(children)             // 批量添加
editor.remove(child?, destroy?)      // 不传则删除当前选中
editor.removeEmptyGroup()
editor.group() / editor.ungroup()
editor.select(ui | ui[]) / editor.cancel()
editor.setNormalizeAttr(child)       // 递归补全 id/name/zIndex/editable
```

### 3.5 视图缩放

```ts
editor.zoom("fit" | "in" | "out" | "100%" | ...);  // 传 IZoomType
editor.zoom(0.5);                                  // 传具体比例
editor.currentScale = 1;                           // 直接设置
```

`zoom` 与设置 `currentScale` 都会触发 `canvasZoomChange` 事件。

### 3.6 导入导出

```ts
editor.toJSON()                      // 全部页面（含 ground/sky）
editor.exportContentJSON()           // 仅内容层 + 元数据
await editor.reLoadFromJSON(json)    // 覆盖式加载（清空后重建）
await editor.appendPagesFromJSON(json) // 追加页面

// 导出当前页
editor.export("a.png", options?)
editor.exportSync("a.jpg", options?)
editor.exportContentAndSky("a.png", options?)
editor.exportSyncContentAndSky("a.jpg", options?)
```

### 3.7 七大管理器

| 管理器 | 关键 API |
| --- | --- |
| `page` | 见 3.2 |
| `history` | `undo()` `redo()` `save()` `clear()` `disable()` `enable()` `canUndo()` `canRedo()` `info()` |
| `layer` | `moveUp/moveDown/moveToTop/moveToBottom(ui)`、`moveIntoGroup/moveOutOfGroup`、`moveBefore/moveAfter`、`normalizeZIndexes` |
| `mode` | `current`、`setNormal()` `setPreview()` `setDraw()` `set(mode)`、`setPenStyle(style?)`、`penStyle` |
| `image` | `open()`（弹窗选图返回 Image）、`hasLocalImages()`、`uploadLocalImages(options?)` |
| `clipboard` | `copy(selected)` `cut(selected)` `paste()` `clear()` `hasItems` |
| `font` | `fontList`、`defaultFonts`、`addCustomFonts(fonts)`、`hasFont(name)`、`findFontByName(name)`、`resolveMissingFonts(json)` |

## 4. LeaferEditorLayout 组件

组件定义于 `src/LeaferEditor/layouts/layout.vue`。

### Props

| Prop | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `editorOptions` | `EditorLayoutOptions` | 否 | 内核配置 + 插件选项（见下） |
| `options` | `LayoutOptions` | 否 | 布局 UI 配置（见第 5 节） |
| `apis` | `LayoutApiOptions` | 否 | 字体 / 模板 / 素材数据接口（见 5.3） |
| `sloganName` | `string` | 是 | 顶部标题 |
| `logoUrl` | `string` | 是 | 顶部 Logo 地址 |

`EditorLayoutOptions` = `LeaferEditorOptions` + 插件选项：

```ts
interface EditorLayoutOptions extends LeaferEditorOptions {
    ruler?: EditorRulerOptions;       // RulerPlugin
    shortcut?: ShortcutPluginOptions; // ShortcutPlugin
}
```

组件内部固定安装：`RulerPlugin`、`ShortcutPlugin`、`ContextMenuPlugin`、`ToolBarPlugin`、`SnapPlugin`。

### Expose

通过 `ref` 可拿到编辑器实例：

```ts
const layoutRef = ref<InstanceType<typeof LeaferEditorLayout>>();
const editor = layoutRef.value?.editor;
```

组件卸载时会自动 `cleanupSelectedProxy()` 并 `editor.destroy()`。

## 5. layoutOptions 配置系统

定义于 `src/LeaferEditor/layouts/layoutOptions.ts`。`layout.vue` 用 `mergeLayoutOptions(editor, userOptions)` 将**用户配置 → 内核 options → 内置默认值**逐级回退合并，再 `provide` 注入，面板通过组合式 API 消费。

```ts
interface LayoutOptions {
    pageAddable?: boolean;
    theme?: LayoutThemeOptions;
    image?: LayoutImageOptions;
    pagination?: LayoutPaginationOptions;
    previewComponent?: Component;
    slots?: LayoutSlotsOptions;
    isShowFooterBar?: boolean;
    isShowPageText?: boolean;
    font?: LayoutFontOptions;
    shape?: LayoutShapeOptions;
    waterfall?: LayoutWaterfallOptions;
    export?: LayoutExportOptions;
    materialDialog?: LayoutMaterialDialogOptions;
    draw?: LayoutDrawOptions;
    thumbnail?: LayoutThumbnailOptions;
    helpShortcuts?: LayoutHelpShortcutItem[];
    headerActions?: Component[];
    headerLeft?: LayoutHeaderLeftOptions;
}
```

### 5.1 配置项总览

| 配置项 | 说明 |
| --- | --- |
| `pageAddable` | 底部页面是否可新增 / 删除（默认 `true`） |
| `theme` | 默认填充 / 描边 / 阴影色 |
| `image` | 上传允许类型、大小上限、预览尺寸（`acceptTypes` 缺省时回退 `editorOptions.image.fileTypes`） |
| `pagination` | 左侧素材面板分页大小，支持全局数字或按面板对象 |
| `previewComponent` | 自定义预览组件，渲染在右侧面板底部 |
| `slots` | 插槽系统（见第 6 节） |
| `isShowFooterBar` | 是否显示底部版权条（默认 `true`） |
| `isShowPageText` | 页面缩略图下方是否显示文字（默认 `false`） |
| `font` | 字号预设、预览文本、字体名后缀、加载超时、默认文字色 |
| `shape` | 各类图形创建时的默认尺寸参数 |
| `waterfall` | 素材瀑布流布局参数 |
| `export` | 导出弹窗文件类型、质量档、默认表单、`onSave` 回调、预览格式 |
| `materialDialog` | 素材弹窗缩略图尺寸 |
| `draw` | 画笔描边预设 |
| `thumbnail` | 底部页面缩略图 / 图层面板缩略图尺寸 |
| `helpShortcuts` | 「帮助」快捷键列表附加内容 |
| `headerActions` | 顶部栏右侧自定义组件数组（渲染在保存按钮左侧） |
| `headerLeft` | 顶部左侧各功能开关 |

### 5.3 数据接口 LayoutApiOptions

布局层不关心数据来源，通过 `apis` 注入；默认实现见 `src/mock`。全部 10 个接口：

```ts
interface LayoutApiOptions {
    queryFontList(params): Promise<Response<FontListData>>
    queryMyFontList(params): Promise<Response<FontListData>>
    uploadFont(file): Promise<Response<FontInfo>>
    queryTemplateList(params & { category?, keyword? }): Promise<Response<any>>
    queryTemplateCategories(): Promise<Response<CategoryListData>>
    queryImageMaterialList(params & { category?, keyword? }): Promise<Response<any>>
    queryImageCategories(): Promise<Response<CategoryListData>>
    queryMaterialList(params? & { category?, keyword? }): Promise<Response<any>>
    queryMaterialCategories(): Promise<Response<CategoryListData>>
    uploadMaterial(req): Promise<Response<Record<string, never>>>
}
```

- `params`：`{ pageSize, pageNum }`
- `Response<T>`：`{ code, msg, data: T }`
- `FontListData`：`{ list: FontInfo[], total }`
- `CategoryListData`：`{ list: { label, value }[], total }`

## 6. 插槽（slots）系统

```ts
interface LayoutSlotsOptions {
    attributeOne?: SlotConfig<AttrSlotCustomItem>;    // 单选属性面板
    attributeSome?: SlotConfig<AttrSlotCustomItem>;   // 多选属性面板
    attributeZero?: SlotConfig<AttrSlotCustomItem>;   // 未选中属性面板
    leftPanel?: SlotConfig<LeftSlotCustomItem>;       // 左侧素材面板
    toolBar?: SlotConfig<ToolBarSlotCustomItem>;      // 顶部工具条
}
```

### 6.1 通用规则

每个插槽配置支持三种操作，由 `resolveSlotList(builtin, config)` 合并：

```ts
interface SlotConfig<TCustom> {
    hidden?: string[];               // 1. 隐藏内置项（按 name）
    order?: Record<string, number>;  // 2. 调整顺序（内置项 + 自定义项均可指定）
    custom?: TCustom[];              // 3. 注入自定义项
}
```

排序规则：按 `order` 升序，`order` 相同则保持原顺序；自定义项未指定 `order` 时默认排在末尾（`1e6`）。内置项默认 order 由 `createCounter(100, 100)` 生成（100、200、300…）。

### 6.2 各插槽内置项与上下文

> **重要**：插槽组件**不通过 props 注入编辑器**，而是通过 `inject` / 组合式 API 获取上下文。自定义组件内请使用下面的 API。

#### attributeOne / attributeSome / attributeZero

渲染位置：右侧面板「属性」页。属性面板根据选中数量在 one/some/zero 间切换（`attribute/index.vue`）。

| 插槽 | 内置项 name |
| --- | --- |
| `attributeOne` | `baseAttr`、`ungroupAttr`、`alignTool`、`canvasAlignTool`、`layerAttr`、`layerNameAttr`、`groupAttr`、`textAttr`、`imageAttr`、`barcodeAttr`、`qrcodeAttr`、`lineAttr`、`arrowAttr`、`rectAttr`、`ellipseAttr`、`polygonAttr`、`starAttr`、`fillAttr`、`strokeAttr`、`shadowAttr` |
| `attributeSome` | `baseAttr`、`layerAttr`、`groupAttr`、`alignTool`、`canvasAlignTool` |
| `attributeZero` | `canvasAttr`、`canvasAutoSizeAttr`、`canvasLocalUpload`、`canvasBgAttr`、`drawAttr` |

**可用上下文**（组件内自行调用）：

```ts
import { useLeaferEditor } from '@/LeaferEditor/layouts/editorContext'
import { selectedProxyData } from '@/LeaferEditor/layouts/selectedProxyData'
import { useLayoutOptions, useLayoutTheme, useLayoutApis } from '@/LeaferEditor/layouts/layoutOptions'

const editor = useLeaferEditor()               // 编辑器实例
const tag = selectedProxyData(editor, 'tag')   // 当前选中元素的响应式属性（如 tag/x/y/fill…）
const opts = useLayoutOptions()                // 完整 layoutOptions
const theme = useLayoutTheme()                 // theme 快捷访问
const apis = useLayoutApis()                   // 数据接口
```

`selectedProxyData(editor, key, defaultValue?, onChangeAndSave?)` 返回 `computed`：

```ts
{
  modelValue,           // 响应式值
  defaultValue,
  onChange(value),      // 写入当前选中元素
  onEnd(),              // 通常用于 history.save()
}
```

#### leftPanel

渲染位置：左侧栏。内置面板：

| name | 说明 | icon（iconfont class） |
| --- | --- | --- |
| `add` | 添加元素（图形 / 文字 / 条码等） | `icon-plus-circle` |
| `template` | 模板列表 | `icon-apps` |
| `material` | 素材列表 | `icon-common` |
| `image` | 图片列表 | `icon-image` |
| `text` | 文字列表 | `icon-font-colors` |

**可用上下文**：同属性面板（`useLeaferEditor` / `useLayoutOptions` / `useLayoutTheme` / `useLayoutApis` / `selectedProxyData`）。

**额外 props**：左侧面板渲染自定义组件时会传入 `active: boolean`，表示当前面板是否激活：

```vue
<script setup lang="ts">
defineProps<{ active?: boolean }>()
</script>
```

#### toolBar

渲染位置：顶部栏中间。内置项：

| name | 说明 |
| --- | --- |
| `group` | 编组（`editor.group()`） |
| `ungroup` | 取消编组（`editor.ungroup()`） |

**注意**：`toolBar` 的自定义项是**配置对象**（不是 Vue 组件），由 `toolBar.vue` 直接渲染为按钮。因此没有组件上下文，需要自己 `useLeaferEditor()` 的场景请改用 `leftPanel` / `attributeX` 插槽或 `headerActions`。

### 6.3 自定义项数据结构

**AttrSlotItem**（属性面板）：

```ts
interface AttrSlotItem {
    name: string;
    component: Component;
    order: number;
    show: () => boolean;   // 返回 false 时不渲染

// 自定义项：Partial<AttrSlotItem> & { name: string; component: Component }
```

**LeftSlotItem**（左侧面板）：

```ts
interface LeftSlotItem {
    name: string;

```

**ToolBarSlotItem**（顶部工具条）：

```ts
interface ToolBarSlotItem {

    disabled: () => boolean;

// 自定义项：Partial<ToolBarSlotItem> & { name; content; iconClass; onClick }
```

**完整示例**：

```ts
const options: LayoutOptions = {
```

## 7. 事件系统

`editor.eventBus` 是类型安全的 `MittBus`，监听时参数类型自动推断：

```ts
editor.eventBus.on(editor.Events.selected, (list: IUI[]) => { /* ... */ });
editor.eventBus.on(editor.Events.canvasZoomChange, (scale: number) => { /* ... */ });
```

### 事件一览

| 分类 | 事件（参数） |
| --- | --- |
| 页面 | `pageAddBefore/After`（`{oldId,newId}`）、`pageChangeBefore/After`、`pageRemoveBefore/After`（`id`） |
| 画布 | `canvasAddBefore/After`（`{_child,_index}`）、`canvasChange`（`PropertyEvent`）、`canvasResize`（`{width,height}`）、`canvasRemoveBefore/After` |
| 选中 | `selectedBefore`、`selected`（`IUI[]`）、`cancelSelected` |
| 视图 | `canvasZoomChange`（`number`） |
| 模式 / 历史 | `changeMode`（`string`）、`undoRedoStackChange`、`historyStateSavedAfter`（`{state,pageId}`） |
| JSON | `loadJSONBefore/After`（`{json}`） |
| 图片 | `imageLocalUploadSuccess`（`{url,newUrl}`）、`imageLocalUploadError`（`{url,error}`） |

### API

```ts
eventBus.on(type, handler)
eventBus.off(type, handler)
eventBus.once(type, handler)
eventBus.emit(type, param)
eventBus.stop() / start()
eventBus.clear(type?)

// 非类型化的外部事件通道（与第三方库 / 后端推送对接）
eventBus.onExternal(name, fn)
eventBus.offExternal(name, fn)
eventBus.emitExternal(name, obj)
eventBus.hasExternal(name)
```

> 项目内部使用外部通道的例子：footer 监听 `updatePagesThumbnail` / `updateCurrentPageThumbnail` 刷新缩略图；copy 操作会 emit `copyToAllPageDone` / `copyToPageDone`。

## 8. 插件系统

任何类继承 `PluginHost` 即获得插件能力；`LeaferEditor` 本身即子类，因此**所有核心能力均由插件提供**。

```ts
interface IPlugin<T = any, O = any> {
    name: string;
    description?: string;
    version?: string;
    author?: string;
    dependentPlugins?: string[];
    dependentServices?: string[];
    install(host: IPluginHost<T>, options?: O): void;
    uninstall?(host: IPluginHost<T>): void;
}
```

宿主 API：

```ts
editor.use(plugin, options?)                 // 安装
editor.unuse(pluginName, autoCleanup?)       // 卸载（自动清理服务与 hook）
editor.getService<T>(name)                   // 取服务
editor.hasService(name) / hasPlugin(name)
editor.registerServiceFor(plugin, name, svc) // 插件内注册服务
editor.getPluginInfo(name) / getPluginInfos()
editor.hook(PluginEvent.install, fn, pluginName?) // 生命周期钩子
```

插件状态机：`pending → installing → installed → uninstalling → uninstalled`，出错进入 `error`。

### 8.1 内置插件与选项

| 插件 | 类名 / name | 服务名 | 选项 |
| --- | --- | --- | --- |
| 快捷键 | `ShortcutPlugin` / `shortcut` | `shortcut` | `{ global?: boolean }` 是否全局绑定（默认绑定到 `editor.view`） |
| 右键菜单 | `ContextMenuPlugin` / `ContextMenu` | `ContextMenu` | 无 |
| 标尺 | `RulerPlugin` / `Ruler` | `Ruler` | `EditorRulerOptions` |
| 浮动工具条 | `ToolBarPlugin` / `ToolBarPlugin` | `toolBar` | 无（通过服务增删按钮） |
| 吸附 | `SnapPlugin` / `snap` | `snap` | 无（自动吸收 Ruler 网格线） |

**EditorRulerOptions**：

```ts
{
    enabled?: boolean;          // 是否启用标尺
    unit?: string;              // 初始单位：px / cm / in / pt / pc / mm
    dpi?: number;               // 仅控制单位显示换算，默认 72
    gridLine?: {
        strokeColor?: string;       // 辅助线颜色，默认 '#1d1dff'
        strokeDragColor?: string;   // 拖动中颜色，默认 '#ff0000'
    };
}
```

内置快捷键（`ShortcutPlugin` 默认绑定）：`mod+z/y`、`mod+a`、`esc`、`del/backspace`、`mod+left/right`、`mod+0/1`、`+/-`、`[`/`]`、`mod+[`/`]`、`mod+g`、`mod+shift+g`、`h`、`mod+c/x/v`、`shift+h/v`、`m/v/p`（模式）、`l`（锁定）、`,/.`（旋转）、`w/a/s/d`（移动）。

### 8.2 插件服务

```ts
import {
    useLeaferEditorShortcutPluginService,
    useLeaferEditorContextMenuPluginService,
    useLeaferEditorRulerPluginService,
    useLeaferEditorToolBarPluginService,
    useLeaferEditorSnapPluginService,
} from "../LeaferEditor";

const shortcut = useLeaferEditorShortcutPluginService(editor);
shortcut.bindShortcut('mod+k', () => { /* ... */ });
shortcut.trigger('mod+a');

const ruler = useLeaferEditorRulerPluginService(editor);
ruler.changeUnit('cm');
ruler.newGridLine(100, 'h');
ruler.toggleEnabled();

const toolbar = useLeaferEditorToolBarPluginService(editor);
toolbar.addItem({ id: 'lock', label: '锁定', onClick: (node) => {} });

const menu = useLeaferEditorContextMenuPluginService(editor);
menu.registerContextMenu(() => ({ key: 'my', title: '我的菜单', type: 'ALL', callback: () => {} }));
```

**ToolBarItem**（浮动工具条按钮）：

```ts
{
    id: string;                 // 唯一标识，重复覆盖
    label?: string;
    icon?: string;              // HTML/SVG 字符串
    onClick?: (node: ILeaf) => void;
    divider?: boolean;
    help?: string | (() => string);
    type?: 'one' | 'some';      // 单选 / 多选时显示
    visible?: (node, type) => boolean;
}
```

**MenuOptions**（右键菜单项）：

```ts
{
    key: string;
    title: string;
    type: 'ALL' | 'ONE' | 'SOME' | 'ZERO' | MenuType[];  // 场景
    desc?: string;
    children?: MenuOptions[];
    callback?: (e: { pointerEvent, mouseEvent, type, key }) => void | boolean;
    showCallback?: () => boolean;
    disableCallback?: () => boolean;
}
```

## 9. 扩展入手点

按「改动面从小到大」排序，推荐优先级如下：

### 1) 监听事件（零侵入）

```ts
editor.eventBus.on(editor.Events.undoRedoStackChange, () => { /* 标记未保存 */ });
editor.eventBus.on(editor.Events.selected, (list) => { /* ... */ });
```

### 2) 通过 layoutOptions 调整 UI

- `slots`：增删改排左侧面板、属性面板、工具条。
- `headerLeft`：按需隐藏顶部功能。
- `headerActions`：注入顶部右侧自定义组件。
- `theme` / `shape` / `export` 等：调整默认值与导出行为。

### 3) 注入数据接口（替换 Mock）

实现 `LayoutApiOptions` 的 10 个方法并通过 `apis` 传入，即可接入真实后端。

### 4) 注册右键菜单 / 工具条按钮 / 快捷键（服务扩展）

```ts
const menu = useLeaferEditorContextMenuPluginService(editor);
menu.registerContextMenu(() => ({ key: 'export-psd', title: '导出 PSD', type: 'ALL', callback: () => {} }));

const toolbar = useLeaferEditorToolBarPluginService(editor);
toolbar.addItem({ id: 'center', label: '居中', onClick: () => {} });

const shortcut = useLeaferEditorShortcutPluginService(editor);
shortcut.bindShortcut('mod+k', () => {});
```

### 5) 编写自定义插件（推荐的能力扩展方式）

```ts
import type { IPlugin, IPluginHost } from "../LeaferEditor";
import type { LeaferEditor } from "../LeaferEditor";

class WatermarkPlugin implements IPlugin<LeaferEditor, { text: string }> {
    name = "Watermark";
    install(host: IPluginHost<LeaferEditor>, options?: { text: string }) {
        const editor = host.getInstance();
        // 使用其他插件服务
        const ruler = editor.getService("Ruler");
        // 注册自身服务
        host.registerServiceFor(this, "Watermark", this);
    }
    uninstall(host: IPluginHost<LeaferEditor>) {
        host.unregisterService("Watermark");
    }
}

editor.use(new WatermarkPlugin(), { text: "即刻设计" });
```

> 若希望插件随 `LeaferEditorLayout` 自动安装，可 fork `layout.vue` 并追加 `editor.use(...)`；或自行基于 `createLeaferEditor` 组装 UI。

### 6) 扩展创建元素能力

- 用 `utils.predefine` 快速创建基础图形。
- 参考 `src/LeaferEditor/core/shapes/QrCode.ts`、`BarCode.ts`，通过 `@registerUI()` + `dataProcessor` + `@boundsType` 注册新的 Leafer UI 类型，即可像内置图形一样参与渲染、编辑、导出。
- 在左侧「添加」面板中增加创建按钮：可通过 `slots.leftPanel.custom` 注入自定义面板，或修改 `addWrap.vue`。

### 7) 自定义吸附元素

`SnapPlugin` 会自动把 Ruler 网格线纳入吸附；如需扩展，可监听其服务或参考 `snap.ts` 中的 `extendElement`。

### 8) 修改布局壳组件

`src/LeaferEditor/layouts/layout.vue` 是 UI 装配中心（安装插件、provide 上下文）。如需改变整体骨架或默认插件组合，可复制该文件为自定义布局。

## 附：注意事项
